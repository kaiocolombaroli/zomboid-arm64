## Included in this repository

### zomdroid (MIT)

Part of `native/` was ported from `zomdroid` (`app/src/main/cpp/`), https://github.com/liamelui/zomdroid. Result of comparing
each file with the upstream directory:

Derived from zomdroid (ported to Windows ARM64, adapted; keeps the upstream design and structure):

- `native/loader/macho_loader.c`, `macho_loader.h` (Mach-O loader)
- `native/loader/macho_bridge.c` (calling-convention bridge; the Apple/AAPCS64 differences are handled here)
- `native/loader/macho_jnienv.c`, `macho_jnienv.h` (JNI environment wrapper)
- `native/loader/macho_jni_table.h` (generated from `jni.h`)
- `native/darwin/dw_string.cpp`, `dw_string.h` (port of upstream `macho_string.cpp/.h`, Apple `std::string` layout)

Original to this repository (no counterpart in zomdroid, or a different implementation; written for this project):

- `native/loader/macho_bridge.h`
- `native/darwin/dw_unwind.c`, `dw_unwind.h` (compact-unwind reader; follows the public LLVM libunwind format, not the upstream code)
- `native/darwin/dw_eh.c`, `dw_eh.S` (C++ exception runtime)
- `native/darwin/dw_alloc.c`, `dw_cxx.cpp`, `dw_format.c`, `dw_fs.c`, `dw_libc.c`, `dw_math.c`, `dw_pthread.c`, `dw_runtime.c`,
  `dw_stdio.c`, `dw_table.c`, `dw_ti.cpp`, `dw_tlv.c`, `dw_tlv.S`, `dw_variadic.S`, `dw_internal.h`, `darwin.h`, `pzdarwin.def`
- `native/bridge/bridge_main.c`, `native/stubs/*`, `native/fmodshim/*`, `native/imports/*`, `native/CMakeLists.txt`, `native/toolchain-llvm-mingw.cmake`

The upstream files that were not ported (Android linker bypass, emulation, pathfind, `wrapped_jni.*`, `zomdroid*.c`) are not present here.

### Symbol and interface lists

`native/imports/` holds lists of symbol names (libc, libc++, and the JNI entry points) that the game's
macOS libraries import or export, and `native/fmodshim/fmodshim_gen.inc` lists FMOD C API function names.
They are interoperability data (names only) used to generate bridge code; they contain no code from the game or from FMOD.
